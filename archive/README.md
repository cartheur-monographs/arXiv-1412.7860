# Archive

This directory keeps non-submission assets that remain useful for provenance,
recovery, or later editorial work, but should stay outside the canonical arXiv
bundle in `arxiv/v.2/`.

## Contents

- `legacy-conversion/`: the earlier `1412.7860v2` TeX and PDF conversion pass
- `figure-extraction/`: raw image objects, page renders, and reconstruction
  intermediates used during figure extraction

## Intent

These files are preserved so the publication workflow remains reproducible
without cluttering the final arXiv source package.

The canonical final figure assets live only in `arxiv/v.2/figures/`.
